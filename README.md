# Qwen3.8 Flash-Next EXL3

A Gufo extension that will serve turboderp's EXL3 checkpoints of Qwen3.8
Flash-Next on Linux x86-64 / Strix Halo `gfx1151`, over the Flash-Next runtime
of Gufo's `qwen38_flash_next` extension.

The extension is being moved out of Gufo; it does not serve a model yet.
